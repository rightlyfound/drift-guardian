# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email
security@rightlyfound.com with the affected version, reproduction steps, and
impact. We will acknowledge receipt within seven days and coordinate a fix and
 disclosure timeline with the reporter.

Please avoid including secrets or personal data in reports. If the address is
not monitored, contact the maintainer through the private security-reporting
mechanism configured for the repository.
